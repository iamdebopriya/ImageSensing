# 🩺 HealthAI: Medical Image Diagnosis & Advice System

## 📖 About
HealthAI is a **Streamlit-based healthcare web app** that uses **CNN models** to predict diseases from medical images.  
It supports **knee osteoarthritis severity detection, lung cancer classification, and chest disease diagnosis**.  
The app also provides personalized **doctor, medication, surgery, and diet advice**.

---

## 🚀 Features
- 🦵 Knee Osteoarthritis detection (5 severity levels)  
- 🫁 Lung Cancer detection (4 cancer types)  
- 🫀 Chest Disease detection (14 classes)  
- 📊 Displays predictions with medical advice  
- 🎨 Clean lavender UI  

---

## 🛠️ Technology
- **Python**  
- **TensorFlow / Keras** (CNN models)  
- **Streamlit** (web interface)  
- **PIL & NumPy** (image preprocessing)  
- **Matplotlib** (visualization)
